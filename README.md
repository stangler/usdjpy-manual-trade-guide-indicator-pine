# usdjpy-manual-trade-guide-indicator-pine

TradingView Pine v6 indicator: USDJPY manual trading guide (Tokyo range breakout levels, SL/TP labels, alerts)

ドル円の**手動売買を支援するインジケーター**です。東京時間のレンジ高値・安値から、エントリーのトリガー価格、損切り・利確の価格を計算してチャートに表示し、売買のタイミングをアラートで通知します。

対応するバックテスト用ストラテジーは [usdjpy-tokyo-range-breakout-strategy-pine](https://github.com/stangler/usdjpy-tokyo-range-breakout-strategy-pine) です。両者は同じ設定値を使います。

- ファイル名（推奨）: `usdjpy-manual-trade-guide-indicator.pine`
- スクリプト名: `ドル円 手動運用ガイド (A:東京レンジ→ロンドン / B:5時売り)`
- 対象: USDJPY / **1時間足**（バックテストは1時間足で検証しています）
- 時刻: 日本時間（入力でタイムゾーンを変更できます）

## 2つの戦略

| 戦略 | 内容 |
|---|---|
| **A: 東京レンジ→ロンドン** | 東京時間（9〜16時）の高値・安値を、17〜19時に終値で抜けたら順張りでエントリー |
| **B: 5時売り** | 火〜金の5:00に売り、6:00に時間決済（損切り・利確なし） |

## 1日のタイムテーブル（日本時間）

| 時刻 | 通知 | やること |
|---|---|---|
| 5:00（火〜金） | B 売りエントリー | ドル円を成行で売る |
| 6:00（火〜金） | B 決済 | 成行で買い戻して決済 |
| 9:00〜16:00 | なし | 何もしない（東京レンジが記録される） |
| 16:00 | なし | 右下の表で、トリガー・損切り・利確の価格を確認する |
| 17:00 / 18:00 / 19:00 | A 買い または A 売り | 通知の方向で成行エントリーし、損切りと利確を同時に設定する。その日の最初の1回のみ。19時以降は新規エントリーしない |
| 翌0:00 | A 時間決済の確認 | 損切り・利確にかからず残っていれば成行で決済する |

## Aの損切り・利確

レンジ幅を R（高値 − 安値）とします。エントリー価格ではなく、**レンジ端**を基準にした価格です。

| | トリガー（1時間足の終値） | 損切り | 利確 |
|---|---|---|---|
| 買い | レンジ高値より上で確定 | 高値 − R × 0.5 | 高値 + R × 0.6 |
| 売り | レンジ安値より下で確定 | 安値 + R × 0.5 | 安値 − R × 0.6 |

### 計算例

レンジ高値 159.800、レンジ安値 159.500（R = 0.300 = 30 pips）の場合です。

| | トリガー | 損切り | 利確 |
|---|---|---|---|
| 買い | 159.800 より上 | 159.650 | 159.980 |
| 売り | 159.500 より下 | 159.650 | 159.320 |

損切りは買いも売りもレンジの真ん中になるため、損切りの線は1本に重なります。

## チャートの表示

- **白い線**: レンジ高値・安値（買い／売りのトリガー）
- **赤い線**: 損切り
- **黄緑の線**: 利確
- **右端のラベル**: 各線の価格（例: `買い利確 160.167`）
- **右下の表**: 買い・売りそれぞれのトリガー、損切り、利確の価格とレンジ幅（pips）
- **背景色**: 灰色=東京レンジ、青=A のエントリー受付時間、黄色=B の保有時間
- 損切り・利確の線とラベルは、16:00 以降に表示されます。翌日 9:00 に新しいレンジが始まると更新されます。

## アラート

アラートは**最初に1回だけ**作成します。条件にこのインジケーターを選び、トリガーは **「バー終値ごとに1回」** にします。

| アラート名 | 通知時刻 |
|---|---|
| A 買い(レンジ上抜け) | 17:00 / 18:00 / 19:00 のいずれか（その日の最初の1回） |
| A 売り(レンジ下抜け) | 17:00 / 18:00 / 19:00 のいずれか（その日の最初の1回） |
| B 売りエントリー | 5:00（火〜金） |
| B 決済 | 6:00（火〜金） |
| A 時間決済の確認(0時) | 0:00（毎日） |

通知が来たら**すぐに成行でエントリー**します。数分以上遅れた場合は見送ります。

## 入力パラメータ

| 項目 | 既定値 |
|---|---|
| タイムゾーン | Asia/Tokyo |
| A レンジ開始時（含む） | 9 |
| A レンジ終了時（含まない） | 16 |
| A エントリー受付終了時（含まない） | 19 |
| A 損切り（レンジ幅倍） | 0.5 |
| A 利確（レンジ幅倍） | 0.6 |
| B エントリー時 | 5 |
| B 保有時間（時間） | 1 |
| B 曜日 | 火・水・木・金 |

数値は、検証した設定のままで使います。結果を見ながら変更すると、過去のデータへの過剰適合につながります。

## 導入手順

1. TradingView の Pine エディタで、**新規のインジケーター**を作成します。
2. `usdjpy-manual-trade-guide-indicator.pine` の内容を貼り付けて、保存します。
3. USDJPY の**1時間足**のチャートに追加します。
4. 上記のアラートを作成します。

スクリプトは**1つずつ別の名前で保存**してください。1つのエディタに別のスクリプトを貼り直すと、元のスクリプトが置き換わります。

## バックテスト実績（対応ストラテジー）

1時間足、期間 2025-01-01〜2026-05-31、10,000通貨、初期資金 200,000円です。この期間は、パターンを見つけた期間（2026年6〜11月）より前のデータです。

| | 損益 | PF | 勝率 | 取引回数 | 最大ドローダウン |
|---|---|---|---|---|---|
| A 単独 | +55,050円 | 1.304 | 63.1% | 168 | 10.4% |
| B 単独 | +46,050円 | 1.561 | 54.3% | 293 | 8.7% |
| **A + B** | **+101,100円** | **1.384** | 57.5% | 461 | 9.5% |
| A + B（スリッページ5ティック） | +76,080円 | 1.277 | 53.8% | 461 | 10.8% |

詳細は、ストラテジーのリポジトリを参照してください。

## 注意事項

- **B には損切り・利確がありません。** バックテストは、6:00 の時間決済のみで動いています。突発的な値動きに備えて逆指値を入れる場合は、検証にない設定になります。
- **夏時間（3〜11月）は、B の決済時刻 6:00 がロールオーバー時刻に重なります。** スプレッドの拡大やスワップの発生を、デモ口座で確認してください。
- B の1回あたりの平均利益は約 1.6 pips と薄く、スプレッドやスリッページに敏感です。
- 検証期間は約 17 か月で、固定ロット（10,000通貨）の結果です。まずデモ口座や最小ロットで、バックテストとの違いを確認してください。
- A の時間決済は、1時間足では**翌 0:00 の始値**で行われる動作です。
